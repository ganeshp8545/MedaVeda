A successful Vite build verifies compilation, not button behavior against Supabase. Login, create, edit, publish, unpublish, delete, search, filters, refresh and pagination across every route remain NOT VERIFIED in a browser/staging environment. The video form can now open a validated YouTube link for preview. The note schema has no description field (MV-009); adding one requires a forward-only database migration and coordinated mobile display. The current MCQ schema is subject-scoped with fixed 20-question content and client-side 30-second question timing; changing that would alter existing test rules and was not done.
