## Form-wide checks before any submission

- **Encryption in transit:** source uses HTTPS and Android cleartext traffic is disabled; inspect final manifest, endpoints, redirects and SDK communications before confirming.
- **Deletion:** Settings exposes Delete Account and `/delete-account` provides an email request path. `erase_user_data` omits newer account-linked records, local data is not fully wiped by the deletion action, and deployed behavior/email processing are unverified. Follow [Play's deletion requirements](https://support.google.com/googleplay/android-developer/answer/13327111) before selecting completion answers.
- **Sharing:** decide service-provider exceptions from current Play definitions and actual contracts for Supabase, Google Play, Expo, Sentry, email delivery and any live Razorpay channel.
- **Required/optional:** registration fields are required for creating an account; purchases, quizzes, searches and notifications depend on feature use. Decide how Console defines automatic usage events within those features.
- **Temporary processing:** no server-side category can be marked temporary-only on this source evidence. Confirm any provider-only transient treatment separately.
- **Retention:** check production `pg_cron`, Supabase backup plan/PITR, payment law/accounting advice and vendor retention. Do not use 12-month, 90-day or eight-year claims without evidence.
- **Final release:** capture package, AAB manifest, dependency/SDK inventory, EAS environment, Play tracks, network/payload observations, Console form and public policy/deletion URLs. Record reviewer/date beside each confirmed answer.
