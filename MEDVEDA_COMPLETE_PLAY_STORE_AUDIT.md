The intended sale products are paid notes/PDF scopes only. Read-only inventory must classify legacy `other` rows before a reviewed server gate and catalog-filter migration; do not alter their prices to resolve this. Prices remain owner controlled; no fixed price is required or recommended. Zero price is retained in Admin but has no Play checkout path. The worker now checks exact India INR BUY pricing, activation and a sole purchase option before marking a tier ready ([worker](supabase/functions/sync-play-catalog/index.ts#L24), [read-back](supabase/functions/_shared/playCatalog.ts#L26)). New V2 verification validates purchase option; the client and catalog now reject ambiguous offers/options because the SDK omits option identity. Google purchase V2 does not provide an authoritative transaction amount field in this resource, so the system relies on a previously verified, immutable catalog tier plus server order snapshot. Website Razorpay integration is separate and was not changed or tested here.
